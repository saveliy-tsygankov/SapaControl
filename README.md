# SAPACONTROL — приёмка квартир в новостройке

Многостраничный статический сайт компании по профессиональной приёмке квартир.
Без сборки, без фреймворков — чистый HTML, CSS и JavaScript.

## Демо

🔗 **Live:** (https://saveliy-tsygankov.github.io/SapaControl/)

## Страницы

- **Главная** — hero, слайдер площади, карточки проблем, табы нарушений, CTA-форма
- **Услуги и цены** — карточки услуг с ценами и списком работ
- **Отчёты** — фильтрация примеров отчётов по типу отделки
- **Калькулятор** — расчёт стоимости с типами квартир, площадью и доп. услугами, модалка заявки
- **Отзывы** — сетка отзывов клиентов
- **О компании** — статистика с анимацией счётчиков, документы
- **Контакты** — контактные данные, форма заявки

## Что реализовано

- Калькулятор стоимости с типами квартир, площадью, доп. услугами и разбивкой по строкам
- Слайдер площади, синхронизированный с калькулятором через `CustomEvent`
- Табы с ролями `role="tab"` / `role="tabpanel"` и `aria-selected`
- Фильтрация отчётов по категориям
- Модальное окно с фокус-менеджментом и локом скролла
- Маска телефона с поддержкой вставки и автозаменой 8 → 7
- Валидация и отправка форм без перезагрузки
- Мобильное меню с Escape, кликом вне, закрытием по ссылке
- Анимация счётчиков через `IntersectionObserver`
- Семантическая вёрстка, ARIA-атрибуты
- Адаптив от 320px

## Стек

- HTML5 (семантические теги, ARIA)
- CSS3 (переменные, Grid, Flex, `:has()`, `clamp`)
- Vanilla JS (ES6+, IIFE, без зависимостей)
- Google Fonts (Golos Text)
